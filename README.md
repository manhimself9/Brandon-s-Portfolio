# Brandon Makombe — Portfolio

A creative, responsive portfolio for a front-end developer, built with plain HTML, CSS, and JavaScript.

## Features
- Responsive layout for mobile, tablet, and desktop
- Custom geometric hero artwork and project previews made with CSS
- Mobile navigation and back-to-top control
- Scroll reveal animations and reduced-motion support
- Semantic markup and no framework/build step required

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Personalize before sharing
- Replace concept projects with real projects and their individual repository/demo links.
- Add a professional email address or other preferred contact method.
- Update your bio and skills as your experience grows.
